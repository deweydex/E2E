Before we start: history is messy

The dates on this page mark when something appeared, not when everyone used it. In 1962 the sociologist Everett Rogers described how new ideas spread: a few innovators first, then early adopters, the majority, and last of all the laggards. Add them up and the total follows an S-curve, slow, then steep, then flat.

Real technologies are untidier than the curve. This chart comes from one survey of the top ten million websites, so the lines can be compared.

  • Overlap. Flash officially ended in December 2020, and about 1 site in 100 still carried it in 2025.
  • Different speeds. WordPress climbed for years, then levelled off at about 43 per cent of all sites.
  • Dependency. Ajax was named in 2005, but it rested on a browser feature from 1999 and on faster connections.

Source: W3Techs surveys of the top ten million websites, 1 January each year. Rogers, Diffusion of Innovations (1962).

The Web Rebuilds Itself

This page is a history of the web, and it rebuilds itself as you scroll. It starts as a plain page from 1991 and ends with the browser you are using today. Each part of the page is built with the tools of its own era, so the page itself becomes the evidence. The words in each part are notes on the story, and the sources are at the end.

The story has four parts, and each idea below is tagged with the parts it is about:

  • HTML is the structure. It says what each part of a page is: a heading, a list, a link.
  • CSS is the look. It sets colours, fonts, spacing and layout.
  • Scripts are the behaviour. JavaScript runs in your browser and changes the page.
  • Server is the computer that sends the page, runs programs and keeps the data.

Over thirty years, jobs moved between these four parts. That movement is the story. The bar at the top of the window is a pretend browser, and it changes as you move through the eras. Press Calm mode in that bar to stop everything that moves.

1991: The first page HTML Server

In 1991 Tim Berners-Lee put the first web page online at CERN, the physics laboratory near Geneva. The page held text and links and nothing else. A reader could not change anything on it. Each click on a link asked a server for a whole new page, and the browser showed that page in place of the old one.

Many people first met the web through the Line Mode Browser, which ran on plain text terminals with no mouse. Each link got a number in square brackets, and the reader typed the number to follow it. The first page looked roughly like this there:

                      World Wide Web
   The WorldWideWeb (W3) is a wide-area hypermedia[1] information
   retrieval initiative aiming to give universal access to a large
   universe of documents.

   Everything there is online about W3 is linked directly or
   indirectly to this document, including an executive summary[2]
   of the project ...

1-24, Back, Up, <RETURN> for more, Quit, or Help:

Every website still starts with this pattern. The browser asks, and the server answers with a page. The first page is still online at info.cern.ch.

How this part is built: with no CSS of its own. You are seeing your browser's default styles: a serif font, blue underlined links and a white page. The terminal box imitates the Line Mode Browser, and you can try the real thing at line-mode.cern.ch.

1993 to 1995: Forms let readers write back HTML Server

NCSA Mosaic, released in 1993, showed pictures beside the text and made the web popular. Its pages had a grey background unless the author chose another colour. In 1995 forms became part of HTML 2.0. A form let a reader type something and send it to the server.

On the server, a program read what the reader sent. Early programs used a system called CGI, short for Common Gateway Interface. The program built a brand new page as its answer and sent the whole page back. Even a small mistake, such as a missing email address, meant a trip to the server and a whole new page.

1995 to 2005: Servers learn to build pages from data Server

Meanwhile the server learned new tricks. PHP was first released in 1995. A PHP file looks like HTML with small pieces of code inside. The server runs that code, fills in the gaps from a database, and sends plain HTML to the browser. The browser never sees the PHP.

On the server:          <p>Hello, <?php echo $name; ?></p>
What the browser gets:  <p>Hello, Aoife</p>

Microsoft's ASP followed in 1996. Later came frameworks such as Ruby on Rails in 2004 and Django, for Python, in 2005. WordPress, launched in 2003, is written in PHP. When you save a post in WordPress, PHP stores it in a database and builds the page from it each time someone visits.

A common setup was called LAMP: Linux, Apache, MySQL and PHP. Addresses on sites like this one often ended in .php?id=42, which told the server which record to fetch. Look at the address in the bar at the top.

How this part is built: with nested tables and a transparent spacer image one pixel high, stretched to push the columns apart. Designers set Verdana at 11 pixels because it stayed readable on the screens of the time. The bevelled tabs are gradients standing in for the sliced button images a 2001 site would use.

1996 to 2020: Plugins fill the gaps Plugins HTML

A plugin is a program added to the browser to do what HTML could not. Flash was the best known. From the late 1990s, whole sites were built in Flash, with animated intros, music and games. Many opened with a loading bar and a Skip Intro button, like the one above.

Flash had real costs. Search engines could not read inside it, screen readers struggled with it, and it was a frequent security risk. In 2007 the first iPhone arrived without Flash. HTML5 added the <video> and <audio> elements, so a page could play a clip on its own. Adobe ended Flash at the close of 2020.

The lesson of Flash is that a feature built into HTML outlasts one added from outside. The same pattern returns with jQuery in the next part, and with scripts in the last one.

How this part is built: Flash no longer runs in any browser, so this intro is drawn with the <canvas> element and JavaScript, the tools that replaced it. The pixel font was a Flash favourite because it stayed crisp at tiny sizes.

2006: jQuery smooths over browser differences Scripts

Each browser of the 2000s ran JavaScript a little differently. John Resig released jQuery in 2006. It gave one short way to write a script, and that script worked in every browser. jQuery became one of the most widely used scripts on the web.

$("#more").slideToggle();

Browsers now agree with each other, and they copied jQuery's best ideas into querySelector and fetch. New sites rarely need jQuery, but many older sites still use it, and it is still maintained.

Tim O'Reilly's 2005 essay gave the name Web 2.0 to a change in who makes the web. Visitors posted comments and reviews, built profiles on social networks, and wrote wikis together. 2014: HTML5 gives HTML new jobs HTML

HTML5 became a W3C standard in 2014. It added semantic tags such as <header>, <nav>, <main>, <article> and <footer>, which say what their content is. It added <video> and <audio>, form rules such as required and type="email", and <canvas> for drawing. It also retired tags that only described looks, because CSS now did that job.

CSS versions: from levels to modules CSS

    Keeping it safe Server Scripts

    SQL injection

    An attacker types SQL into a form to change the query. A parameterised query keeps what they typed apart from the SQL.

    Cross-site scripting

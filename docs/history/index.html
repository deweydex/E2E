A history of the web in three views

Pages Through the Ages

The same story told three ways. From the Browser watches HTML, CSS and scripts. Behind the Page watches the servers that answer and the databases that remember. Down the Wire watches the networks and protocols that carry everything. Each view comes as an era-by-era page that changes its look with the decade, a slide deck, notes that read on their own, and a PowerPoint file. All three use the same colours for the parts of a website.

The OS isn’t the filesystem.

An operating system runs programs and manages resources. A filesystem organises named objects on a volume. These are three common pairings, not the only possibilities: each OS can use other filesystems too.

A small vocabulary

What this model leaves out

This is a browser-only teaching model, not an emulator or a view of your device. Directory and metadata records also live on storage and are cached in RAM. The panels separate their roles, not their physical locations. The 4-byte cells below are deliberately tiny teaching units; real allocation units are commonly thousands of bytes. We omit permission failures, links, mounts, concurrent access, encryption, compression, sparse files and detailed crash recovery. Metadata may be cached even in a “cold” data read. Actual systems can reorder and combine work.

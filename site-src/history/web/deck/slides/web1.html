Web 1.0: a few people wrote, and many people read

Roughly 1991 to 2004

Pages were mostly fixed documents, like a brochure.

Most visitors could read, but not add anything.

Layout was built from tables, and style was written into tags such as <font>.

Most changes still meant loading a whole new page from the server.

The name Web 1.0 was given afterwards, to contrast with Web 2.0. Nobody called it that at the time. Ask: what sites today still work like Web 1.0? A restaurant menu page or a simple brochure site are good answers.

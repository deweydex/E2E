A rollover, then and now

1999: a script in the tag

<div
onmouseover="this.style
.background='orange'"
onmouseout="this.style
.background='navy'">
Point at me
</div>

Today: one CSS rule

<div class="box">
Point at me
</div>

.box:hover {
background: orange;
}

Both change colour when the pointer moves over the box. The CSS version is shorter, keeps the look in one place, and still works if scripts are switched off.

The gold code is a script, and the blue code is CSS: the job moved from one colour to the other. Ask which one would be easier to change across a whole site.

Look it up, then answer

A language model only knows what was in its training data. To answer questions about your own documents, it needs to look them up first.

This pattern is called retrieval-augmented generation, or RAG: a server finds the closest rows in a vector database, then hands them to the model along with the question.

2020

Researchers at Facebook AI name and describe retrieval-augmented generation.

2021

pgvector adds vector search to PostgreSQL.

2023

Vector databases become a product category of their own, as chat assistants spread.

RAG is a three-tier application in disguise: a front end asks, a server program decides, a database remembers. Only the kind of search is new.

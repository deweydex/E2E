The colour key

One green box, opened up

HTML

The structure of the page the server sends back.

CSS

The look of that page. The server only delivers it.

Scripts

Code in the browser that sends requests and shows replies.

Server

A program that listens for requests and decides what to send.

Database

The place that remembers data after every request has ended.

Seen from the browser, everything behind the page looks like one green box called the server. This talk opens the box: the program that answers stays green, and the database that remembers is purple.

Every slide carries a tag in these colours, with its name written on it, so nobody has to rely on colour alone. Most of this deck lives in green and purple, and the front-end colours appear only where the browser meets the server.

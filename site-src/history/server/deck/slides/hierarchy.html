Database

First, data lived in trees

A tree of records

IBM’s IMS, built for the Apollo programme in the late 1960s, stored data as a tree. A customer record held its orders, and each order held its items.

Follow the path

To find something, a program walked down the tree one level at a time. A new kind of question often meant writing a new program.

Customer → Order 17 → Item 3

The data was fast to read along the paths the designers planned, and slow or impossible to read along any other path.

IMS is still in use in some banks. The point for students: the shape of the storage decided which questions you could ask. The next slide shows the idea that broke that link.

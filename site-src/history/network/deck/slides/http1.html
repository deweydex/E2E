HTTP: the web’s own protocol

HTTP is the protocol a browser and a web server use. It runs on top of TCP, so it can assume every byte arrives.

GET /index.html HTTP/1.1
Host: www.example.ie

1991 · HTTP/0.9

One line: GET and a path. The answer was HTML and nothing else.

1996 · HTTP/1.0

Adds status codes such as 404, and headers that describe the content, so images could travel too.

1997 · HTTP/1.1

Keeps a connection open for several requests, and adds the Host header, so one server could hold many sites.

The Host header changed the business of the web. Before it, every site needed its own IP address. After it, one cheap server could host hundreds of small sites, which is what made shared hosting so cheap.

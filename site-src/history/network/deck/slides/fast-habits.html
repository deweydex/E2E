Five habits for every network

Weigh the page

Check the total size in the developer tools. Images are usually the heaviest part.

Right-size images

Serve small images to small screens, in modern formats.

Load lazily

Let images and scripts below the fold wait.

Cache

Tell browsers and CDNs how long files can be kept.

Test slow

Throttle the connection in the developer tools and watch the page load.

Each habit answers a constraint from this history: the modem, the phone, the distance, and the page that grew.

Every browser's developer tools can pretend to be a slow 3G phone. Trying a site that way for a minute teaches more than any rule.

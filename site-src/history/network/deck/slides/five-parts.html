The colour key

The road under every request

HTML

The page itself, which has to travel to the reader.

CSS

The look of the page, sent alongside it.

Scripts

Code in the browser that opens connections and sends requests.

Server

The computer at the other end that answers.

Network

The wires, radios and agreed rules that carry every byte between them.

The rules are called protocols: agreements about how two machines talk. Teal marks the network and its protocols, which carry everything else.

Every slide carries a tag in these colours, with its name written on it, so nobody has to rely on colour alone. Most of this talk is teal. The other colours appear where a change in the network changed what pages, scripts or servers could do.

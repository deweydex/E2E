Where does a file live?

A file is not just a name. It is a collection of bytes that can be stored, found, opened, and changed by the operating system.

Example: path = "/home/josh/notes.txt"

The text in the string tells Python and the OS how to locate the file. Its contents are separate from the filename, and the bytes are what persist on disk.

Same idea, different implementations

The OS is not the filesystem.

Different operating systems map names to storage structures in slightly different ways, but the idea is the same: a path resolves to a file record, and the file record points to bytes stored on a device.
